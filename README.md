# AI챗 기억 도우미 (AI Chat Memory Assistant)

크랙(crack.wrtn.ai) 롤플레이에서 AI가 지난 일과 설정을 잊지 않도록 돕는 Tampermonkey 스크립트입니다.

- 턴을 세다가 정리할 때가 되면 배지로 알려 드립니다.
- 지난 이야기를 경과로 정리해 크랙 장기기억에 넣도록 돕습니다(되돌리기 가능).
- 상태창이 작품 원래 형식에서 벗어나면 찾아 고칩니다.
- 로어(인물·장소 같은 설정)와 지금 사실을 보낼 때 함께 붙입니다.

## 사용 설명서

**[사용법 보기](사용법.md)** · [사용법 내려받기(.html)](https://raw.githubusercontent.com/LikeGale/crack-chat-helper/main/%EC%82%AC%EC%9A%A9%EB%B2%95.html)

패널 머리줄의 **사용법 보기**를 누르면 같은 설명서가 새 창에서 열립니다. 왼쪽(휴대폰은 오른쪽 아래 **차례**)의 차례로 항목을 바로 찾아갈 수 있고, 파일로 받으려면 설명서 안의 **내려받기**를 누르십시오.
패널의 기능 이름 옆 **ⓘ** 아이콘을 누르면(PC는 마우스를 올리면) 그 기능의 짧은 설명이 뜹니다.

## 설치

1. 브라우저에 [Tampermonkey](https://www.tampermonkey.net/)를 설치합니다. 휴대폰에서는 Tampermonkey를 쓸 수 있는 브라우저(예: 안드로이드 Firefox, Kiwi)가 필요합니다.
2. 아래 링크를 엽니다. Tampermonkey 설치 화면이 뜨면 <strong>설치(Install)</strong>를 누릅니다.

   **[AI챗 기억 도우미 설치하기](https://raw.githubusercontent.com/LikeGale/crack-chat-helper/main/crack-progress-helper.user.js)**

3. 크랙 채팅 화면을 새로 고칩니다. 화면 구석에 '경과 +N턴' 배지가 뜨면 설치가 끝난 것입니다.

## 업데이트

위 링크로 설치했다면 새 버전이 나올 때 Tampermonkey가 저절로 업데이트합니다.
바로 받으려면 Tampermonkey <strong>대시보드(Dashboard)</strong>에서 도우미 줄의 <strong>업데이트 확인(Check for updates)</strong>을 누르십시오.
