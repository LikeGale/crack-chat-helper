# 크랙 경과 정리기

크랙(crack.wrtn.ai) 롤플레이용 Tampermonkey 스크립트예요.

## 설치

1. 브라우저에 [Tampermonkey](https://www.tampermonkey.net/)를 깔아요. 휴대폰은 Tampermonkey를 쓸 수 있는 브라우저(예: 안드로이드 Firefox, Kiwi 등)가 필요해요.
2. 아래 링크를 열면 Tampermonkey 설치 화면이 떠요. **설치**를 누르세요.

   **[크랙 경과 정리기 설치하기](https://raw.githubusercontent.com/LikeGale/crack-chat-helper/main/crack-progress-helper.user.js)**

3. 크랙 채팅 화면을 새로 고치면 구석에 '경과 +N턴' 배지가 떠요.

## 업데이트

이 링크로 설치했다면 새 버전이 나올 때 Tampermonkey가 알아서 업데이트해요.
바로 받고 싶으면 Tampermonkey 대시보드에서 **업데이트 확인**을 누르세요.

> 예전에 스크립트 내용을 직접 붙여 넣어 설치했다면, 위 링크로 한 번만 다시 설치하세요. 이름이 같아서 저장해 둔 설정은 그대로 남아요.

---

크랙에서 롤플레이를 하다 보면 대화가 길어지고, AI가 앞 내용을 잊기 시작해요.
정리기는 **턴을 대신 세다가, 때가 되면 지난 이야기를 '경과'로 정리해 크랙 장기기억에 넣도록** 도와줘요.
어느 작품에서나 쓸 수 있고, 작품마다 설정을 따로 기억해요.

## 한눈에 보기

| 하고 싶은 일 | 어디서 |
|---|---|
| 정리한 뒤 몇 턴 지났는지 보기 | 화면 구석의 **배지** |
| 경과 정리를 Claude에게 맡기기 | 패널 **경과 정리** 탭 |
| Claude가 써 준 경과를 장기기억에 넣기 | 패널 **답 넣기** 탭 |
| 상태창이 망가졌는지 보고 고치기 | 패널 **상태창** 탭 |
| 몇 턴마다 정리할지 바꾸기 | 패널 **경과 정리** 탭 진행 현황 |
| 턴 세는 법 등 바꾸기 | 패널 **설정** 탭 |

## 배지: 늘 떠 있는 작은 알림

크랙 채팅 화면 구석에 **'경과 +12턴'** 같은 배지가 떠 있어요. 마지막으로 정리한 뒤 지난 턴 수예요.

- **색으로 때를 알려 줘요.** 평소에는 기본색이고, 정리할 때(기본 30턴)가 5턴 남으면 노랑으로 바뀌어요. 정리할 때가 지나면 빨갛게 천천히 깜빡여요.
  기기에서 '동작 줄이기'를 켜 두었다면 깜빡이지 않고 빨간색으로만 보여요.
- **빨간 점**이 붙으면 최근 상태창이 작품 원래 모양에서 벗어났다는 뜻이에요. 상태창 탭에서 확인하세요.
- **누르면 패널이 열려요.**
- **끌어서 옮길 수 있어요.** 옮긴 자리를 기억해요. 키보드로는 배지를 고른 뒤 화살표 키로 옮겨요.
- 휴대폰에서는 누르기 쉽게 조금 더 크게 보여요.
- 턴은 알아서 세요. 다른 채팅으로 옮기면 그 채팅 기준으로 새로 세요.

## 패널 열고 닫기

- **PC**
  - 패널 제목 부분을 잡고 끌면 원하는 곳으로 옮길 수 있어요. 옮긴 자리는 다음에 열 때도 그대로예요.
  - 패널을 연 채로 채팅을 누르거나 스크롤해도 패널이 닫히지 않아요.
  - **Esc**를 누르거나 **닫기**를 누르면 닫혀요.
- **휴대폰**: 패널 바깥을 누르거나, **닫기**나 **뒤로가기**를 누르면 닫혀요. 뒤로가기를 눌러도 채팅 화면은 그대로 있어요.

패널 맨 위에는 지금 작품 이름, 내 캐릭터 이름(크랙 페르소나), 이 작품 설정 요약이 보여요.
처음 보는 작품이면 정리기가 대화를 보고 설정을 짐작해 채워 두고, 노란 안내로 맞는지 확인해 달라고 해요.

## 경과 정리하기 (가장 자주 쓰는 순서)

### 1단계: 정리할 파일 만들기 (경과 정리 탭)

1. **진행 현황**에서 지금 턴과 마지막으로 정리한 턴을 확인해요.
   몇 턴마다 정리할지도 여기서 바꿀 수 있어요. **정리 알림** 칸에 턴 수를 적고 **적용**을 누르세요(Enter도 돼요).
2. **정리할 범위**는 '마지막 정리 다음 턴부터 지금 턴까지'로 미리 채워져 있어요. 필요하면 바꿔요.
   처음 정리하는데 턴이 많이 쌓였다면 정리 알림 턴 수만큼씩 나눠 보내도 돼요.
3. 아래에 지금 장기기억 칸들이 보여요. 정리기가 자동으로 쓰는 칸과 직접 추가한 칸을 나눠 보여 줘요. 보내기 전에 고쳐도 돼요.
4. **파일 저장** 또는 **전체 복사**를 눌러 Claude에게 보낼 글을 만들어요.
   이 글에는 정리할 대화, 지금 장기기억, 경과 쓰는 규칙, 상태창 점검 결과가 모두 들어 있어요.
5. 그 글을 Claude에게 보내요.
6. 다 보냈으면 **정리 완료(턴 N까지)**를 눌러 어디까지 정리했는지 기억시켜요.

> 장기기억만 따로 보관하고 싶으면 **장기기억만 따로 저장 / 복사**를 쓰세요.

### 2단계: Claude 답을 장기기억에 넣기 (답 넣기 탭)

1. Claude가 써 준 답을 **통째로 붙여 넣어요.** 코드 블록이 있든 없든, 파일로 받았든 다 읽어요.
2. **미리 보기**에서 항목마다 어느 칸에 들어가는지 확인해요.
   (바꿈 · 같음 · 그대로 · 지움 · 문제 등으로 표시되고, 글자 수와 첫 줄·끝 줄도 보여요.)
   예전 답을 잘못 붙였거나 글자 수가 이상하면 경고가 떠요.
3. **장기기억에 넣기**를 눌러요. 지우는 칸이나 경고가 있으면 한 번 더 눌러야 들어가요.
4. 넣은 뒤 실제로 들어갔는지 다시 확인하고, 크랙 장기기억 창도 새로 고쳐요.

**잘못 넣었을 때는 되돌리기를 누르세요.** 넣기 전 내용으로 돌아가요(지운 칸도 되살려요).
되돌리지 못한 칸은 **원래 내용 복사**로 직접 넣을 수 있어요.

> 안심하고 쓰도록: 직접 추가한 장기기억 칸은 건드리지 않아요. 넣는 사이 크랙에서 장기기억이 바뀌었으면 멈춰요. 창 두 개에서 동시에 넣지 않게 막아요.

## 상태창 점검과 고치기 (상태창 탭)

AI가 응답 끝에 붙이는 상태창이 어느 순간 모양이 바뀌거나 항목이 빠질 때가 있어요. 정리기가 이걸 찾아 줘요.

- **기준은 작품 제작자가 만든 상태창 모양이에요.** 정리기가 대화에서 꾸준히 나오는 모양을 읽어서 기준으로 삼아요.
  내가 입력창에 붙여 넣은 견본 상태창이나, 그 견본을 따라 쓴 응답은 기준으로 쓰지 않아요.
- **점검 결과**: 최근 상태창이 정상인지 보여 줘요. 어긋났으면 빠진 항목, 있으면 안 되는 말, 예전에 어긋났던 턴을 알려 줘요.
- **고치기**: 마지막으로 정상이던 상태창 값으로 빈칸을 채운 상태창을 만들어 줘요. 직접 고쳐도 돼요.
  **턴 N 상태창 바꾸기**를 누르면 크랙 응답을 바로 고치고, **복사**로 가져갈 수도 있어요.
- **상태창 형식 바꾸기**는 필요할 때만 해요.
  - 점검 켜기/끄기
  - 상태창 코드 블록 이름(예: Info, status)
  - **추가할 항목**: 원래 모양에 더 있어야 하는 항목
  - **뺄 항목·있으면 안 되는 말**: 나오면 안 되는 항목이나 글자
  - 바꾸는 즉시 '이 설정이면 최근 상태창 정상/어긋남'을 미리 보여 줘요. 맞으면 **이 작품 설정 저장**.

## 설정 (설정 탭)

### 이 작품 설정 (작품마다 따로)

- **턴 세는 법**
  - 응답 속 턴 표시로 세기: 상태창에 '턴:12', 'Turn 12', '[12턴]' 같은 표시가 있으면 그 모양을 적어요(예: `턴:N`).
    본문 속 '쿨타임 3턴' 같은 엉뚱한 숫자는 알아서 걸러요.
  - 응답 수로 세기: 턴 표시가 없는 작품이면 이걸로.
- **경과에 꼭 남길 것**: 약속, 빚, 관계 변화처럼 경과에서 빠지면 안 되는 것.
- **이 작품 추가 규칙**: 이 작품에만 붙는 정리 규칙.
- **대화 보고 다시 채우기**: 설정이 헷갈리면 대화를 보고 다시 짐작해 채워 줘요(저장해야 적용돼요).

### 모든 작품 공통 설정

- 알림 턴(기본 30): 몇 턴마다 정리할지. 경과 정리 탭의 정리 알림 칸과 같은 값이에요.
- 항목당 글자 수(기본 280), 경과 최대 개수.
- 경과 칸 상한: 칸이 너무 많아지면 Claude가 경과를 합쳐 줄이게 해요(0이면 안 함). 20개 안팎을 권해요.
- 점검할 어색한 표현: 적어 두면 정리할 범위에서 그 표현이 나온 턴을 찾아 줘요(비우면 안 함).
- 모든 작품 공통 추가 규칙.
- **배지 자리 처음으로**: 배지를 원래 자리로 돌려요.

### 다른 기기로 설정 옮기기

**설정 코드 복사**를 눌러 다른 기기의 정리기에서 **가져오기**하면 공통 설정과 작품 설정이 함께 옮겨져요.
배지 자리와 패널 자리는 기기마다 따로예요.
어디까지 정리했는지는 장기기억 경과 제목('경과3 · 턴61~90')으로 다른 기기와 저절로 맞춰져요.
